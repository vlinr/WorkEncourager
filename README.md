# 💰 上班鼓励器（Work Encourager）

> 把上班的每一秒，变成看得见、数得清、还会跳的红色数字。

一个 **零安装、零编译、双击即运行** 的 Windows 桌面薪资实时累计小工具。
它不生产钱，它只是让你亲眼看见：自己正在赚钱。

---

## 🎉 这是个什么玩意儿？

你亲眼看过自己的工资"生长"吗？

「上班鼓励器」是一个免安装、免编译的 Windows 桌面小玩意，双击就能开工：
点下"开始上班"的那一刻，一枚泛着红光的 LED 大数字从 `0.0000` 开始跳动，
精确到小数点后 4 位，每眨一次眼，它就悄悄多出几分钱；
进度条一点点爬向下班时间，那是今天的终点线；
一旦越过下班点，加班火焰点亮，状态栏吼你一句："已多赚 xx 元！"

想提前溜？下班按钮死死灰着，门都没有。
只有当下班铃声响起、按钮亮起的瞬间，你才有资格拍下它——
然后全屏彩带雨倾盆而下、庆祝旋律响起，
一张列得明明白白的薪资单弹出：正常薪资、加班时长、加班费、计薪口径，一目十行。

**上班很苦，但数字跳动的样子，真的很治愈。**

## ✨ 功能特性

- ⏰ **班次自定义**：上班时间、下班时间自由设置，支持跨零点班次（夜班友好）
- 💵 **日薪 / 月薪切换**：默认日薪；月薪按国家法定月计薪天数 **21.75 天** 自动折算日薪，边输边算
- ⚡ **加班计费**：班次时段之外的时间（含深夜、跨天空档）按自定义加班时薪累计
- 🌙 **跨天连续上班**：按自然日循环计薪，每天班次段计日薪、其余时段计加班，跨天不打卡也算得清
- 📅 **每日明细**：工作面板与汇总单按自然日实时拆分：上班时长 / 班次内 / 加班 / 当日收入
- 💾 **历史结算记录**：本地持久化保存，设置页随时查看，纯离线不上传
- 🔁 **未结算班次接续**：中途关闭程序不丢班次，下次启动提示"继续上一班 / 作废"
- 🔴 **红色 LED 累计数字**：60ms 高频刷新，保留小数点后 4 位，辉光拉满，激励感拉满
- 🚪 **下班门禁**：未到下班时间按钮禁用置灰；到点自动解锁 + 铃声提醒，杜绝早退幻想
- 🔥 **加班模式**：进度条变金、状态文案变火焰，实时播报"已多赚 xx 元"
- 🧾 **下班汇总单**：当日总额、上下班时间、班次内薪资、加班时长、加班费、计薪口径、每日明细全列出
- 🎊 **庆祝画面**：Canvas 彩带雨 220 片 + Web Audio 现场合成庆祝旋律（无音频文件依赖）
- 🔊 **音效合成**：开工音、下班铃、庆祝旋律全部由振荡器实时合成，失败自动静默不报错

## 📐 计薪规则

1. **累计起点**：薪资按**班次时间窗口**累计（而非点击按钮的时刻）。
   早上 9 点准时开工，数字从 `0.0000` 起跳；中途补打卡，则已工作的时间也算你的——活是真干了，钱就该是真赚了。
2. **班次内 / 加班拆分（按自然日循环）**：以班次锚点为起点，每个自然日内的班次时段（上班时刻~下班时刻）按日薪秒费率累计；
   **班次时段之外的一切时间**（深夜、跨天空档）一律按加班时薪累计。
   `正常秒数 = 完整天数 × 班次秒数 + 当日已进班次秒数`；`加班秒数 = 总秒数 − 正常秒数`。
3. **跨天未打下班卡**：程序跨过零点自动进入次日循环（次日班次段重新计日薪）；
   中途关闭程序也没关系，下次启动会提示"继续上一班"，锚点不变、累计不断。
4. **月薪模式**：`日薪 = 月薪 ÷ 21.75`（劳动法口径的法定月计薪天数）
5. **显示精度**：金额保留小数点后 4 位。

## 🧰 技术栈

| 技术 | 用途 |
|---|---|
| **HTA（HTML Application）** | Windows 原生应用格式，`mshta.exe` 加载，独立桌面窗口 |
| **HTML + CSS** | 界面与视觉：渐变背景、光斑、LED 辉光数字，纯 CSS 无图片资源 |
| **JavaScript（严格 ES5）** | 业务逻辑；刻意只用 ES5 语法以兼容系统 IE 内核（Trident/MSHTML） |
| **Canvas 2D** | 下班彩带雨庆祝动画 |
| **Web Audio API** | 振荡器实时合成开工音 / 下班铃 / 庆祝旋律 |
| **FileSystemObject（HTA 全信任）** | 历史记录与未结算班次的本地读写，纯离线 |

一个文件 = 一个桌面程序。

## ❓ 常见问题

**Q：为什么我下午才打开，一进来就显示几百块？**
A：因为薪资按班次时间窗口累计（见「计薪规则」第 1 条）。你 9 点上班、16 点打开，前面 7 个小时是你真干掉的活，钱当然该算给你。

**Q：Mac 能跑吗？**
A：HTA 是 Windows 独有组件，Mac 没有对应运行时。Mac 用户可将源码另存为 `.html` 后用 Chrome / Edge 的"以窗口模式创建快捷方式"获得近似独立窗口体验。

**Q：能不能改成"点按钮那一刻才从 0 起算"？**
A：当前规则是班次窗口累计；如需要点击起算模式，欢迎提 Issue / PR。

**Q：会不会偷传我的数据？**
A：全程离线运行，无网络请求、无存储、无上报。源码就一个文件，欢迎逐行审查。
